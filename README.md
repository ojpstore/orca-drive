# Google Drive

Orca 오른쪽 사이드바에서 Google Drive 파일을 탐색·검색하고, 열고, 올리고, 내려받고, 정리하는 플러그인입니다.
패널(`panel/index.html`)이 화면과 드래그 앤 드롭을, worker(`worker.mjs`)가 OAuth 로그인과 Drive REST v3 호출을 맡습니다. 외부 의존성은 없습니다.

## 화면 구성

```
┌──────────────────────────────────────┐
│ (O) Google Drive          [↗] [⎋]    │  계정 · 웹에서 Drive 열기 · 로그아웃
│     user@gmail.com                   │
├──────────────────────────────────────┤
│        [⬆] [📁+] [🗑] [≡] [⟳] [⇕]    │  툴바
├──────────────────────────────────────┤
│ [🔍 필터 · Enter: Drive 검색      ]  │  필터 / 검색
├──────────────────────────────────────┤
│ ▾ 내 드라이브                        │
│   › 📁 문서                          │  폴더 트리
│     📄 보고서.pdf           1.2 MB   │
├──────────────────────────────────────┤
│ 보고서.pdf      ▓▓▓▓░░░░  [✕]        │  전송 진행률 (있을 때만)
│ 상태 메시지                          │  상태줄
└──────────────────────────────────────┘
```

### 툴바 버튼

| 버튼 | 기능 |
|---|---|
| ↗ 웹에서 열기 | 브라우저에서 이 계정의 Google Drive를 엽니다. |
| ⎋ 로그아웃 | 확인 팝업 후 로그아웃합니다(토큰도 취소). |
| ⬆ 파일 업로드 | 파일 선택 창을 열어 대상 폴더로 올립니다(여러 개 선택 가능). |
| 📁+ 새 폴더 | 이름을 입력받아 대상 폴더 안에 만듭니다. |
| 🗑 휴지통 | 선택한 항목을 확인 후 휴지통으로 보냅니다. 선택이 없으면 비활성. |
| ≡ 정렬 | 이름 / 수정한 날짜 / 크기, 오름·내림차순을 고릅니다. |
| ⟳ 새로 고침 | 펼친 폴더를 모두 다시 읽습니다. |
| ⇕ 모두 펼치기·접기 | 펼친 폴더가 있으면 모두 접고, 없으면 불러온 폴더를 모두 펼칩니다. 아이콘이 상태에 따라 바뀝니다. |

**대상 폴더**: 새 폴더·업로드 버튼·패널 빈 곳에 놓기는 *선택한 폴더*로 갑니다. 파일을 선택했으면 그 파일이 있는 폴더, 아무것도 선택하지 않았으면 내 드라이브입니다.

## 기본 조작

### 탐색
- `›`를 누르거나 폴더를 더블클릭하면 펼치고 접습니다.
- 하위 목록은 처음 펼칠 때 불러오고, 펼친 폴더의 하위 폴더 목록은 뒤에서 미리 받아 두어 다음 클릭이 바로 열립니다.
- 파일 아이콘은 확장자(또는 Google 문서 종류)에 맞는 Material 아이콘으로 표시됩니다.

### 선택
| 조작 | 동작 |
|---|---|
| 클릭 | 한 항목 선택 |
| `Ctrl` + 클릭 | 선택에 더하기 / 빼기 |
| `Shift` + 클릭 | 범위 선택 |
| `Ctrl` + `A` | 화면에 보이는 항목 모두 선택 |
| 내 드라이브 행 클릭 · `Esc` | 선택 해제 |

여러 항목을 선택한 상태로 끌어 옮기거나 휴지통으로 보낼 수 있습니다.

### 키보드 단축키 (트리에 포커스가 있을 때)
| 키 | 동작 |
|---|---|
| `↑` / `↓` | 위·아래 항목으로 이동 (`Shift`와 함께면 범위 선택) |
| `Home` / `End` | 맨 위·맨 아래 항목 |
| `→` | 폴더 펼치기, 이미 펼쳤으면 첫 하위 항목으로 |
| `←` | 폴더 접기, 아니면 상위 폴더로 |
| `Enter` | 파일 열기 / 폴더 펼치기·접기 |
| `F2` | 이름 바꾸기 |
| `Delete` | 휴지통으로 |
| `Esc` | 선택 해제 |

필터 입력칸에서 `↓`를 누르면 트리로 포커스가 옮겨집니다.

### 우클릭 메뉴
| 대상 | 메뉴 |
|---|---|
| 파일 | 열기 · 웹에서 열기 · 링크 복사 · 다운로드 · 이름 바꾸기 · 사본 만들기 · 휴지통으로 |
| Google 문서·시트·슬라이드·그림 | 브라우저에서 열기 · 링크 복사 · *형식별 다운로드* · 이름 바꾸기 · 사본 만들기 · 휴지통으로 |
| 폴더 | 펼치기/접기 · 웹에서 열기 · 링크 복사 · 새 폴더 · 여기에 파일 업로드 · 이름 바꾸기 · 휴지통으로 |
| 여러 항목 | 다운로드 (N개, 파일만) · 휴지통으로 (N개) |
| 빈 곳 | 새 폴더 · 파일 업로드 · 새로 고침 (대상: 내 드라이브) |

- **링크 복사**는 Drive 링크(`webViewLink`)만 복사하며 공유 설정은 바꾸지 않습니다. 받는 사람에게 권한이 있어야 열립니다.
- **사본 만들기**는 같은 폴더에 `이름 (1).확장자`로 만듭니다(폴더는 Drive API가 복사를 지원하지 않아 제외).

## 필터 · 검색 · 정렬

- **필터**: 입력칸에 치는 즉시 *지금까지 불러온* 트리에서 이름에 그 글자가 든 항목과 그 상위 폴더만 보입니다. 일치 항목이 있는 폴더는 자동으로 펼쳐집니다.
- **Drive 전체 검색**: `Enter`를 누르면 Drive 전체에서 이름 또는 본문에 그 글자가 든 파일을 찾습니다(휴지통 제외, 최대 200개). 결과에서 폴더는 그 자리에서 펼칠 수 있습니다. `Esc`로 트리로 돌아갑니다.
- **정렬**: 폴더는 늘 위에 오고, 그 안에서 이름(숫자는 자연 정렬, 영문이 한글보다 먼저) / 수정한 날짜 / 크기로 정렬합니다. 수정한 날짜로 정렬하는 동안은 크기 대신 날짜를 보입니다.

## 열기 · 다운로드

- **더블클릭 / `Enter`**: 파일을 **다운로드 폴더**(`~/Downloads`)에 받아 OS 기본 프로그램으로 엽니다. Google 문서·시트·슬라이드와 Office 파일(docx·xlsx·pptx 등)은 Drive 뷰어로 브라우저에서 엽니다.
- **우클릭 → 다운로드**: 다운로드 폴더에 저장만 하고 열지는 않습니다.
- **Google 문서 변환 다운로드** (우클릭):

  | 종류 | 받을 수 있는 형식 |
  |---|---|
  | 문서 | Word (.docx) · PDF · 텍스트 (.txt) |
  | 시트 | Excel (.xlsx) · CSV (첫 시트) · PDF |
  | 슬라이드 | PowerPoint (.pptx) · PDF |
  | 그림 | PNG · PDF |

- 다운로드는 백그라운드로 진행되어 크기 제한이 없고, 아래에 진행률 막대와 **✕(취소)** 가 나옵니다. 취소하거나 실패하면 받다 만 파일은 지웁니다.
- 같은 이름 파일이 이미 있으면 덮어쓰지 않고 `a (1).txt`처럼 번호를 붙입니다. 파일 이름의 경로 문자(`\ / : * ? " < > |`)는 `_`로 바꿉니다.
- ⚠ 실행 파일(.exe 등)도 그대로 실행되니 출처가 확실한 파일만 여세요.

## 업로드

- **방법**: 툴바 ⬆ 버튼, 우클릭 → 파일 업로드, 또는 탐색기에서 끌어다 놓기.
  - 폴더 행 위에 놓으면 그 폴더로, 빈 곳에 놓으면 대상 폴더로 올라갑니다.
  - **폴더째 놓으면** 하위 폴더 구조를 Drive에 그대로 만들고 파일을 올립니다.
- 4 MiB 조각의 재개 가능 업로드이며, 진행률 막대와 **✕(취소)** 를 보입니다. 취소하면 Drive가 받은 조각도 버립니다.
- **같은 이름 파일이 있을 때** 팝업에서 고릅니다.

  | 선택 | 결과 |
  |---|---|
  | 새 버전으로 덮어쓰기 | 기존 파일의 새 버전으로 올립니다. 이름·위치·공유는 그대로이고 이전 내용은 Drive 버전 기록에 남습니다. |
  | 별도 저장 | `이름 (1).확장자`로 새 파일을 만듭니다. |
  | 취소 | 그 파일만 건너뜁니다. |

## 이동 · 이름 바꾸기 · 삭제

- **이동**: 항목(여러 개 가능)을 폴더 행으로 끌어다 놓습니다.
- **이름 바꾸기**: `F2` 또는 우클릭. 파일은 확장자를 뺀 부분이 선택된 채 입력칸이 열립니다.
- **삭제**: 확인 팝업 후 **휴지통**으로 보냅니다. 영구 삭제가 아니므로 Drive 휴지통에서 30일 안에 복구할 수 있습니다.
- 작업이 끝나면 바뀐 폴더(만든 곳, 지운 곳, 이동 출발지·도착지)만 다시 읽어 빠르게 갱신합니다.

## 알아 둘 점

- 필터는 *불러온* 폴더만 거릅니다. 아직 펼치지 않은 깊은 폴더까지 찾으려면 `Enter`로 Drive 전체 검색을 쓰세요.
- 모두 펼치기는 누를 때마다 한 단계씩 더 깊이 불러옵니다(드라이브 전체를 한 번에 펼치지 않음).
- 폴더째 업로드할 때 같은 이름의 폴더가 이미 있어도 합치지 않고 새로 만듭니다.
- 여러 항목 다운로드는 파일만 받고 폴더는 건너뜁니다.

## 처음 설정

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 만들고 **Google Drive API**를 사용 설정합니다.
2. OAuth 동의 화면을 설정합니다(외부, 테스트 모드면 본인 계정을 테스트 사용자로 추가).
3. 사용자 인증 정보 → **OAuth 클라이언트 ID**, 유형 **데스크톱 앱**으로 만듭니다.
4. 패널에 Client ID와 Client secret을 넣고 저장 → **Google 계정으로 로그인**.

로그인은 PKCE + `127.0.0.1` 임의 포트 리디렉션(데스크톱 앱 방식)으로 하며, 클라이언트 값과 refresh token은 Orca 암호화 저장소(`secrets:own`)에 둡니다. 범위는 기존 파일을 다루기 위해 `drive` 전체입니다. 앱이 검증 전이라 Google이 "확인되지 않은 앱" 경고를 보이면 **고급 → 이동**으로 진행합니다.

## 문제 해결

| 증상 | 원인 · 해결 |
|---|---|
| 로그인 페이지에서 `로그인 실패: fetch failed (SELF_SIGNED_CERT_IN_CHAIN …)` | 회사 보안 프로그램(예: Somansa)이 HTTPS를 검사하는 환경입니다. worker는 OS 인증서 저장소를 함께 신뢰하므로 최신 버전에서는 해결됩니다. 그래도 나면 그 루트 인증서가 Windows 인증서 저장소에 있는지 확인하세요. |
| 로그인 탭이 연결 거부로 끝남 | 로그인 버튼을 여러 번 눌렀다면 마지막에 열린 탭에서 진행하세요. 대기는 최대 5분입니다. |
| `redirect_uri_mismatch` | OAuth 클라이언트 유형이 **데스크톱 앱**이 아닙니다. |
| `access_denied` | 테스트 모드에서 로그인한 계정이 테스트 사용자로 등록되지 않았습니다. |
| 링크 복사가 실패 | 클립보드 접근이 막힌 환경이면 상태줄에 링크를 보여 줍니다. |

## 개발

```sh
node --test worker.test.mjs
orca plugin validate .
orca plugin dev watch .                      # 처음 로드 때 --approve 필요
orca plugin dev request . drive.list --data '{"parent":"root"}'
```

### 파일 구조
| 파일 | 역할 |
|---|---|
| `orca-plugin.json` | 매니페스트 (`trusted-worker`, `secrets:own`) |
| `worker.mjs` | OAuth 로그인, Drive REST 호출, 다운로드 작업·업로드 세션 |
| `panel/index.html` | 화면, 선택·키보드·메뉴·드래그 앤 드롭, 전송 UI |
| `panel/lib.mjs` | DOM 없는 순수 로직(정렬, 필터, 이름 중복, 범위 선택, 변환 형식) |
| `panel/icons/` | 파일·폴더 아이콘 SVG |
| `worker.test.mjs` | `worker.mjs`·`panel/lib.mjs` 테스트 |

### worker 요청 (`orca.plugin.request`)
| 이름 | 입력 | 설명 |
|---|---|---|
| `auth.status` / `auth.config` / `auth.begin` / `auth.signOut` | | 로그인 상태·클라이언트 설정·로그인 시작·로그아웃 |
| `drive.about` | | 로그인한 계정 메일 |
| `drive.list` | `parent` | 폴더 목록 (휴지통 제외) |
| `drive.search` | `text` | 이름·본문 검색 (최대 200개) |
| `drive.mkdir` / `drive.rename` / `drive.copy` | `parent,name` / `id,name` / `id,name` | 폴더 생성 / 이름 변경 / 사본 |
| `drive.move` / `drive.trash` | `id,from,to` / `id` | 이동 / 휴지통 |
| `download.start` / `download.cancel` | `id,name,exportMime?,open?` / `job` | 백그라운드 다운로드(변환 포함) 시작·취소 |
| `upload.start` / `upload.chunk` / `upload.cancel` | `parent,name,mimeType,size,replaceId?` / `id,offset,total,data` / `id` | 재개 가능 업로드 |

worker가 패널로 보내는 이벤트: `auth.changed`, `download.progress`, `download.done`, `download.error`.
